请求时区

真实 OpenAI OAuth 请求按账号改写环境上下文；默认使用新加坡，不提供中国大陆及港澳台时区。

请求中已有的 Accept-Language 会统一为 en-US,en;q=0.9；没有该请求头时不会额外添加。

Excel2API

指定账号通过 BPS Responses 接口访问 Excel2API，沿用该账号的授权和代理设置。

目标：https://bps.openai.com/basispoints/api/responses

客户端工具会转换为自然语言目录并通过 run_officejs 桥接；用户消息中的 data:image 会先上传为 BPS file_id，工具返回的截图保持原格式回放。其他接口（如 compact）沿用原线路。

Excel2API 专用测试

在插件内验证 BPS 请求格式、授权、代理和响应桥接。

先开启“启用测试”，保存 Excel2API 开关、账号 ID 和检测模型，再点击下面的专用按钮；测试结果会显示在“最近一次检测”。

降智检测

选择多个 GPT 模型后按账号和模型并行发送正式 Responses 请求，并用 ModelTrace 指纹判断是否匹配。
